# Interactive Portfolio Website

## Description

This project is an interactive portfolio website built for Week 3 JavaScript practice in `Task3`. It keeps the same single-page portfolio structure from the earlier tasks, but adds JavaScript features such as dark mode, a slider, a to-do list, and live form validation.

The page uses an external `script.js` file to handle DOM manipulation, event listeners, reusable functions, and local storage for user preferences. It is designed to feel polished on desktop and mobile screens.

## Setup Instructions

1. Open the `Task3` folder in VS Code or your preferred editor.
2. Open `index.html` in a browser to view the portfolio.
3. Make sure `style.css` and `script.js` stay linked to the HTML file.
4. Replace the sample content, social links, and email address with your own details.
5. Add or replace images inside the `images/` folder if you want different visuals.
6. Refresh the browser after making changes to test the updates.

## Project Files

- `index.html` - main portfolio page
- `style.css` - external stylesheet for layout, color, and responsiveness
- `script.js` - JavaScript for interaction, validation, and content updates
- `images/` - image assets used by the page

## Features

- External JavaScript file linked to HTML
- Dark and light mode toggle with local storage
- Interactive image slider
- To-do list with add and remove functionality
- Contact form validation with error messages
- Show and hide content button
- DOM manipulation and reusable functions
- Event listeners for click, input, and submit actions

## Notes

The form is validated in the browser before showing a success message. Because this is a static project, it does not send messages to a backend service.
