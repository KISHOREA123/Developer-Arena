# Styled Portfolio Website

## Description

This project is a responsive personal portfolio website built in `Task2`. It showcases a clean hero section, about content, skills, and a contact form using semantic HTML, an external stylesheet, modern typography, and a balanced color scheme.

The page is designed to look polished on desktop and mobile screens. It uses Flexbox and CSS Grid for layout, hover effects for links and buttons, and a reusable card-based design to keep the content easy to scan.

## Setup Instructions

1. Open the `Task2` folder in VS Code or your preferred editor.
2. Open `index.html` in a browser to view the portfolio.
3. Edit the text, email address, and social links to match your own information.
4. Replace `images/profile.svg` with your own profile image if needed.
5. Refresh the browser after making changes to see the updated design.
6. Add screenshots to the `screenshots/` folder before submitting the project.

## Project Files

- `index.html` - main portfolio page
- `style.css` - external stylesheet for layout, colors, and responsiveness
- `images/` - image assets used by the page
- `screenshots/` - folder for submission screenshots

## Features

- External `style.css` file
- Google Fonts typography
- Flexbox and CSS Grid layout
- Hover effects for navigation links and buttons
- Responsive design for mobile screens
- Styled form, cards, and profile section

## Notes

The contact form uses a `mailto:` action, so it opens the user's email client from a static page. If you want a live form later, you can connect it to a backend service or form provider.
