# Styled Portfolio Website

This project is a styled personal portfolio website built in `Task2`. It uses semantic HTML, an external stylesheet, responsive layout rules, and a clean color scheme to create a polished single-page portfolio.

## Features

- External `style.css` file
- Custom Google Fonts typography
- Flexbox and CSS Grid layout
- Hover effects for navigation links and buttons
- Responsive design for mobile screens
- Styled form, cards, and profile section

## Files

- `index.html` - main portfolio page
- `style.css` - external stylesheet
- `images/` - image assets used by the page
- `screenshots/` - place screenshots here for submission

## How to Use

1. Open `index.html` in a browser.
2. Replace the placeholder text, email address, and links with your own details.
3. Add screenshots to the `screenshots/` folder before submission.
